# Guess and test model

Trueswell & Gleitman 2011 guess-and-test model

## Usage

``` r
guess_and_test(f, sa)
```

## Arguments

- f:

  forget at retrieval

- sa:

  prob of storage (slow learning down)

## Value

An object of class xslMod

## Examples
