# Stevens et al. 2014 pursuit model

Stevens et al. 2014 pursuit model

## Usage

``` r
pursuit(gamma, threshold, lambda)
```

## Arguments

- gamma:

  learning rate

- threshold:

  threshold (probability) to move an association to the known lexicon

- lambda:

  smoothing probability

## Value

An object of class xslMod

## Examples

mod <- pursuit(gamma = .2, threshold = .3, lambda = .05)
xsl_run(mod, get_example_ambiguous_condition())
